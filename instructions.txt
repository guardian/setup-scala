   1. Install and initialise gh-aw in this checkout:  gh extension install github/gh-aw , then  gh aw init .                                                                                                                                      ┃
   2. Implement the specification as  .github/workflows/setup-scala-v2-migration.md . Its frontmatter must configure manual dispatch, dry-run/apply/tracking modes, repository selection, the AI engine, read tools, and safe-outputs. The        ┃
      Markdown body supplies the migration instructions.                                                                                                                                                                                          ┃
   3. Configure access. Set up the chosen AI engine’s authentication and a narrowly scoped GitHub App for cross-repository operations. Workflow-file changes require additional permission; this repository’s default  GITHUB_TOKEN  alone is     ┃
      insufficient.                                                                                                                                                                                                                               ┃
   4. Compile and review: run  gh aw compile setup-scala-v2-migration --strict . Resolve errors and warnings, then review and commit both the source  .md  and generated  .lock.yml , plus any required supporting files.                         ┃
   5. Merge into the default branch, then launch it from GitHub’s Actions → Run workflow, initially selecting dry-run mode and one repository. Alternatively, use  gh aw run setup-scala-v2-migration , which prompts for inputs.                 ┃
                                                                                                                                                                                                                                                  ┃
   Important: your migration’s dry-run mode must explicitly prevent writes.  gh aw compile --dry-run  is a compiler diagnostic mode, not a read-only migration run.                                                                               ┃
